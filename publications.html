Hybrid Reach-Avoid MPC with Backstepping Control

With Shankar Deka, Aalto University

Model predictive control over a finite horizon can reach a state from which no feasible continuation exists, and the optimiser simply fails. This controller integrates exponential control barrier functions into a backstepping design, so that the reach-avoid set the barrier produces certifies that a feasible solution always remains available.

Network-Optimal Decentralised Bilevel Optimisation

With Mayank Baranwal, IIT Bombay

A single-loop decentralised bilevel optimiser combining Chebyshev-accelerated consensus with optimistic gradient tracking. The work establishes communication lower bounds and network-optimal complexity, isolating the independent effects of network topology, outer-level conditioning and inner-adjoint conditioning.

Gradient-Flow Methods for Bilevel Optimisation

With Mayank Baranwal, IIT Bombay · Undergraduate Research Award, 2025

Applies the Polyak-Lojasiewicz inequality to the lower-level function of a continuous bilevel problem with a non-convex upper level, guaranteeing asymptotic convergence under minimal assumptions. The method uses a hypergradient estimator with Tikhonov regularisation to avoid singularity in the Hessian inverse, and a projection operator to keep gradients bounded.

Point Cloud Generation from Raw Data

With Leena Vachhani, IIT Bombay

A grid segmentation algorithm that selects only the vehicles relevant to real-time path planning and collision avoidance, benchmarked against ball trees, approximate nearest neighbours and k-d trees. Computation time falls to 0.193 seconds per timestep.
